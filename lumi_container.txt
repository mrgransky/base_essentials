Pipeline Steps:

Phase 1: Disable Old Conda Setups in Your User Environment
$ cd
$ rm -rf ~/.cache
$ vim ~/.bashrc

Comment out or delete the line:

# export PATH="/projappl/project_462001213/CondaCSC/bin:$PATH"

# # Architecture-aware Tykky container path
# ARCH=$(uname -m)
# if [ "$ARCH" = "aarch64" ]; then
#     export PATH="/projappl/project_462001213/CondaCSC/bin:$PATH"
# elif [ "$ARCH" = "x86_64" ]; then
#     export PATH="/projappl/project_462001213/CondaCSC_cpu/bin:$PATH"
# fi

Save and exit: Esc => :wq!

Apply ~/.bashrc Changes and Verify:

The most reliable way is to log out of Puhti and log back in.

Alternatively, for the current session (less complete than a fresh login): source ~/.bashrc

Verify:

$ echo $PATH
$ which python

Phase 2: Delete the Old CondaCSC Directory Content

$ module purge
$ module load LUMI lumi-container-wrapper
$ cd /projappl/project_462001213/

Recreate the Empty Directory for the New Installation:
We need an empty directory for lumi-container-wrapper to install into.

$ rm -rf CondaCSC packages.sh environment.yml && ls -l
$ mkdir -v CondaCSC && ls -l

Phase 3: Create the New lumi-container-wrapper Environment (Named CondaCSC)

This phase uses lumi-container-wrapper to build a fresh, clean environment.

Prepare environment.yml and requirements.txt:

Create environment.yml (e.g., in your home directory or /projappl/project_462001213/) with your desired Conda packages.

$ vim environment.yml

name: CondaCSC_env
channels:
  - conda-forge
dependencies:
  - python=3.12
  - pip
  - setuptools
  - wheel
  # Core runtime libs
  - libstdcxx-ng>=14
  - libgcc-ng>=14
  - sqlite
  - icu
  - openssl
  - zlib

# verify there are no tabs before re-running:
$ cat -A environment.yml | grep '\^I'

$ conda-containerize new --prefix CondaCSC environment.yml

# Phase 4: Set Up PATH for the New CondaCSC Environment
$ cd
$ vim ~/.bashrc

# add the following line to the end of ~/.bashrc
export PATH="/projappl/project_462001213/CondaCSC/bin:$PATH"

Save and exit: Esc => :wq!
Log out of Puhti or Mahti (cttl + d) and log back in (most reliable).

Or source ~/.bashrc.

Verify:

$ echo $PATH
$ which pip

which python and pip should now point to locations inside /projappl/project_462001213/CondaCSC/bin/.

Test the New Environment:
$ python -VV

continue with package installation:
$ module purge
$ module load LUMI lumi-container-wrapper
$ cd /projappl/project_462001213/

$ vim packages.sh
